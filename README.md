# TenderAI - Умный поиск госзаказов

AI-платформа для анализа и поиска перспективных госзакупок.

## Возможности:
- Парсинг основных площадок госзакупок
- AI-оценка выгодности тендеров
- Рекомендательная система
- Уведомления о новых заказах

## Технологии:
- Python + FastAPI
- Machine Learning
- PostgreSQL
- React
